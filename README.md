# Vigil

Vigil turns a spare Android phone into a home security camera. It detects movement, people, pets, vehicles and important sounds on the phone itself and saves clips to your own Google Drive. A second phone, or a web browser, lets you watch and get alerts.

Vigil is in development. The first release has not been published yet.

This repository holds the app's public website:

- [Home page](https://customgpter.github.io/vigil/)
- [Privacy policy](https://customgpter.github.io/vigil/privacy.html)
- [Terms of use](https://customgpter.github.io/vigil/terms.html)

The site is plain HTML and CSS with no scripts, cookies or tracking, and is served by GitHub Pages from the `main` branch.
