# Vigil

Vigil turns a spare Android phone into a home security camera. It detects movement, people, pets, vehicles and important sounds on the phone itself and saves clips to your own Google Drive. A second phone, or a web browser, lets you watch and get alerts. It has no adverts, no subscription and no paid version.
